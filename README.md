### 2. Dự án SauceDemo Web & Usability Testing
- Nội dung thực hiện:
  - Bắt lỗi giao diện và chức năng giỏ hàng của tài khoản `problem_user`.
  - Phân tích Network Request, giả lập mạng chậm (Network Throttling 3G) và Audit hiệu năng trang web với công cụ Google Lighthouse (đạt điểm 100/100).
  - Đánh giá khả năng tiếp cận (Accessibility) bằng công cụ WAVE Tool và phân tích trải nghiệm người dùng theo 10 nguyên lý Heuristics của Jakob Nielsen.

### 3. Kiểm thử Hiệu năng với Apache JMeter (Performance Testing)
- Nội dung thực hiện:
  - Xây dựng kịch bản kiểm thử tải (Load Testing) giả lập 20 người dùng đồng thời (20 Threads, Ramp-up 5s, Loop 2).
  - Áp dụng Response Assertion để kiểm tra tính toàn vẹn dữ liệu trả về từ Server.
  - Phân tích báo cáo Aggregate Report với thông số Throughput đạt 9.8 req/sec và tỷ lệ lỗi Error 0.00%.

### 4. Kiểm thử Bảo mật cơ bản (Security Testing)
-Nội dung thực hiện:
  - Mô phỏng và viết Test Cases kiểm tra phòng chống tấn công SQL Injection và Cross-Site Scripting (XSS).
  - Kiểm tra tính năng che giấu mật khẩu và cơ chế phòng chống dò mật khẩu Brute-Force.
